# Case status comes from c of n runs, reported with a Wilson interval

None of the eval tools report a rule-based flaky status or a confidence interval, and pooled stddevs mix case-to-case and run-to-run spread. drill reports, per case and model, the run vector, `c/n`, the pass rate and a Wilson 95% interval, with status `pass` (c = n), `fail` (c = 0) or `flaky` (otherwise), the rule Bazel and Develocity use. Runs that fail for infrastructure reasons are `error` and left out of n; `plugin eval` scores API-error runs 0, so drill reclassifies them. No pooled stddev is reported. `claude plugin eval` keeps its default of 3 runs, raised for release results. Researched in [Cross-model runs: run count and reporting of variance](https://github.com/dworznik/drill/issues/4) ([findings](https://github.com/dworznik/drill/blob/research/run-count-variance/research/run-count-variance.md)).
